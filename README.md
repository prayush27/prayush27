I study computer science at UW–Madison, class of ’29, and mostly write Python and Java.

Right now I’m building **MadPlan**, a class planner for UW–Madison students. You upload your DARS and it works out what you still need, picks classes that count toward it using live seats and past grade distributions, and builds a weekly schedule around your preferences. It’s a Flask app that reads the degree audit PDF, checks prerequisites against your record and searches every section combination, so you don’t have to look up classes one at a time.

Before that I built coursework projects in Java: a red-black tree, the backend for a game leaderboard, and a small version-control system with its own stack and queue.
